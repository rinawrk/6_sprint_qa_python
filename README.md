# Sprint_6

Финальный проект 6 спринта по UI-тестированию сервиса **Яндекс.Самокат**.

## Allure-отчёт

Отчёт опубликован через GitHub Pages:  
[Allure Report](https://rinawrk.github.io/6_sprint_qa_python/)

## Описание проекта

В проекте реализованы UI-автотесты для сервиса **Яндекс.Самокат**.

Проверяются:
- блок **«Вопросы о важном»**;
- позитивный сценарий **оформления заказа самоката**;
- переходы по **логотипам Самоката и Яндекса**.

Проект выполнен с использованием **Page Object Model (POM)**.  
Для формирования отчётов подключён **Allure**.

## Что проверяют тесты

### FAQ
Проверяется, что при клике на вопрос открывается корректный текст ответа.  
Для всех вопросов используется параметризация.

### Оформление заказа
Проверяется полный позитивный сценарий оформления заказа:
- через верхнюю кнопку **«Заказать»**;
- через нижнюю кнопку **«Заказать»**.

Для каждого варианта используется отдельный набор тестовых данных.

### Логотипы
Проверяются переходы:
- по логотипу **Самоката** - на главную страницу сервиса;
- по логотипу **Яндекса** - на страницу **Дзена** в новой вкладке.

## Особенности реализации

- Для динамических элементов - FAQ, списка станций метро и вариантов срока аренды - используются шаблоны локаторов.
- Для блока FAQ используется параметризация по данным из `data.py`: в тест передаются номер вопроса и ожидаемый текст ответа.
- При выборе станции метро и срока аренды нужный элемент находится по тексту значения из тестовых данных.
- Для сценария заказа используются два отдельных теста: через верхнюю и нижнюю кнопку **«Заказать»**.
- Дата доставки вводится вручную в поле ввода с подтверждением через `Enter`.
- Для проверки перехода по логотипу Яндекса реализована работа с новой вкладкой и ожидание итогового URL.

## Назначение файлов

- `tests/` - тесты, сгруппированные по функциональности;
- `pages/` - page object классы страниц;
- `locators/` - локаторы элементов;
- `config.py` - URL страниц;
- `data.py` - тестовые данные;
- `conftest.py` - фикстура драйвера Firefox;
- `requirements.txt` - зависимости проекта.
